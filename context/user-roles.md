# User Roles

## Workspace Admin (developer / founder)
- Full access to workspace settings, billing, member management
- Can configure agents, tools, knowledge
- Can set per-user controls and tiers
- Can view analytics and run history
- Receives analytics insights

## Workspace Editor (PM, customer success, technical writer)
- Can edit tools and knowledge
- Can view analytics and run history
- Cannot change billing or member access
- Cannot delete agents

## Workspace Viewer (read-only)
- Can view analytics, run history, configuration
- Cannot edit anything
- Useful for stakeholders, executives, support team observers

## End User
- The developer's user, not a Midsphere user
- Never logs into Midsphere directly
- Identified by ID from the developer's auth system
- Has per-user controls applied to them
- Submits ratings via SDK
- Their session logs visible to workspace members
