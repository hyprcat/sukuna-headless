# Audit Tracker

This file tracks Codex audit progress against `context/todo.md`. The TODO is the
product checklist; this tracker records which slices have already been audited
so a fresh session can continue without re-discovering prior work.

## Fresh-Session Start Rule

If the user says only "start", immediately audit:

then continue Phase 8 in `context/todo.md` order.

Do not ask what to audit unless the user redirects to a different phase or item.

## Tracker Rules

- Append or update this file after every completed audit.
- Mark only the exact checklist item, files, and behaviors that were audited.
- Separately list what was not audited or remains pending.
- Entries marked `Seeded from TODO audit note` come from existing audit notes in
  `context/todo.md`; do not spend tokens re-auditing them unless the user asks.
